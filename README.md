# ZizoChat Web

نسخة طبق الأصل تفاعلية من WhatsApp Web تعمل مباشرة في المتصفح كنموذج أولي واقعي.

## المميزات

- شاشة تسجيل دخول برمز QR وهمي (انقر للمسح المحاكاة)
- شريط جانبي مع بحث، قائمة محادثات، حلقات الحالات، مؤشرات الاتصال
- منطقة دردشة كاملة: فقاعات رسائل، رسالة التشفير، ردود، تفاعلات إيموجي
- رسائل صوتية بتموجيات (Waveform) وتحكم بالسرعة (1x, 1.5x, 2x)
- إرسال صور واستطلاعات رأي تفاعلية
- محادثات جماعية بأسماء ملونة وشارة "مشرف"
- نوافذ مكالمات صوتية وفيديو منبثقة
- قوائم جانبية: معلومات الاتصال وإعدادات الملف الشخصي
- وضع داكن وفاتح مع التبديل
- محاكاة انقطاع الشبكة
- حفظ البيانات محلياً (LocalStorage)
- تصميم متجاوب (موبايل وديسكتوب) باللغة العربية (RTL)

## التقنيات

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Lucide React (الأيقونات)
- React Context API + LocalStorage

## التشغيل

```bash
npm install
npm run dev
```
